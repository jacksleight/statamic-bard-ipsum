# Bard Ipsum Lab

Development lab for [`jacksleight/statamic-bard-ipsum`](../statamic-bard-ipsum), pulled in over a composer path repository so edits in the package are live here.

Runs at http://statamic-bard-ipsum--lab.test/ (Herd parks `~/Packages`). Log in at `/!/skip/admin`.

A `tests` collection with an entry per case, each with its own blueprint and template, and a `demos` collection holding the entry the marketplace screenshots are taken from. The addon only runs in the control panel, so the index links each entry's edit screen as well as its page.

See `CLAUDE.md` for the full layout.
